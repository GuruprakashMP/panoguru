Guess the World

You are dropped somewhere on Earth. Look around, walk the road, then pin the spot on the map. Five rounds, up to 5,000 points each.

Best game: 0 pts

How to play
  • Drag to look around, pinch or scroll to zoom, tap the arrows to move.
  • Tap the small map to open it, tap where you think you are, then press Guess.
  • Score = 5000 · e−distance / 1493 km. Within 25 m = perfect.

Imagery and maps © Google. Country outlines: Natural Earth. Source code · Change API key

One-time setup

This game shows Google Street View, which needs a Google Maps API key. The key is stored only in this browser.

How to create a key: see the README (Google Cloud → Maps JavaScript API → restrict to this site → set quotas).
